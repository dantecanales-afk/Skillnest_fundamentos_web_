Ya, cabros, tranquilos. Para el examen de certificación, en JavaScript solo nos tenemos que aprender 5 cosas, que están en los CORES. Nada más. Les armé esta guía para que la tengan a mano, la lean con calma y prueben todo acá mismo.

Los 5 contenidos importantes son:

  1. Contadores usando un botón (en el mismo botón = fácil, o en otro elemento = medio)
  2. Cambiar propiedades de un elemento del DOM: color, value, tamaño y display
  3. Eliminar un elemento de la página al apretar un botón
  4. Leer un input / barra de búsqueda / select y mostrar en una alerta lo que eligió el cliente
  5. Cambiar el src de las imágenes

Con estas 5 cosas pueden hacer el examen sin drama. En serio.

⭐ Antes de partir: la receta mágica

Fíjense que TODOS los ejercicios se hacen con los mismos 3 pasos. Si se aprenden esto, tienen el 80% listo:

  1. Seleccionar el elemento HTML con document.querySelector() y guardarlo en una variable.
  2. Escuchar cuando pase algo (un click, pasar el mouse) con addEventListener().
  3. Hacer el cambio que nos piden adentro de la función.
// PASO 1: seleccionar (el # es porque buscamos por id)
const miBoton = document.querySelector("#miBoton");

// PASO 2: escuchar el click
miBoton.addEventListener("click", function () {

  // PASO 3: aquí adentro va lo que queremos que pase
  
});
⚠️ OJO: el <script> va al final del body, justo antes de </body>. Si lo ponen arriba, el JavaScript se lee antes que el HTML exista y el querySelector no encuentra nada (les va a dar null y error).

1) Contadores con botón

1.A — Contador en el mismo botón (fácil)

La idea: cada vez que aprieto el botón, el número que está dentro del botón sube en 1.

El HTML:

<button id="btnContador">0</button>

El JavaScript, paso a paso:

// 1. Creamos una variable que parte en 0.
//    Aquí vamos a ir guardando cuántos clicks van.
//    Usamos "let" y no "const" porque este número VA A CAMBIAR.
let contador = 0;

// 2. Con esta línea hacemos una variable que va a contener
//    el botón del HTML, y lo seleccionamos usando querySelector.
//    El # significa "búscalo por su id".
const btnContador = document.querySelector("#btnContador");

// 3. Le decimos al botón: "cuando te hagan click, haz esto".
btnContador.addEventListener("click", function () {

  // 4. Le sumamos 1 al contador.
  //    (también se puede escribir contador++ , es lo mismo)
  contador = contador + 1;

  // 5. Escribimos el número nuevo DENTRO del mismo botón.
  //    innerText cambia el texto que está adentro del elemento.
  btnContador.innerText = contador;
});

1.B — Contador en otro elemento (medio)

Ahora el botón está por un lado y el número aparece en otro elemento (un párrafo). La única diferencia es que tenemos que seleccionar dos cosas: el botón y el párrafo.

El HTML:

<p id="numero">0</p>
<button id="btnSumar">Sumar +1</button>
<button id="btnRestar">Restar -1</button>

El JavaScript, paso a paso:

// 1. La variable que guarda el número, parte en 0.
let cuenta = 0;

// 2. Seleccionamos el párrafo donde se va a MOSTRAR el número.
const numero = document.querySelector("#numero");

// 3. Seleccionamos los dos botones.
const btnSumar = document.querySelector("#btnSumar");
const btnRestar = document.querySelector("#btnRestar");

// 4. Cuando hacen click en "Sumar"...
btnSumar.addEventListener("click", function () {
  // ...le sumamos 1 a la cuenta
  cuenta = cuenta + 1;
  // ...y lo mostramos en el PÁRRAFO (no en el botón)
  numero.innerText = cuenta;
});

// 5. Lo mismo pero restando.
btnRestar.addEventListener("click", function () {
  cuenta = cuenta - 1;
  numero.innerText = cuenta;
});

0

💡 Tip: Fíjense que es EXACTAMENTE lo mismo que el 1.A. Lo único que cambia es dónde escribimos el número. Si en el examen les dicen "muestra el contador en un span", es igual, solo seleccionan el span.

2) Cambiar propiedades de un elemento

Aquí nos pueden pedir cambiar 4 cosas: color, value, tamaño y display. Casi todo se cambia con .style, menos el value.

El HTML:

<h3 id="titulo">Soy un título común y corriente</h3>
<button id="btnColor">Cambiar color</button>
<button id="btnTamano">Hacer grande</button>

<input type="text" id="nombre" placeholder="escribe algo...">
<button id="btnValue">Cambiar value</button>

<p id="secreto">🙈 Soy un párrafo que se esconde</p>
<button id="btnOcultar">Mostrar / Ocultar</button>

2.A — Color

// Seleccionamos el título que queremos cambiar.
const titulo = document.querySelector("#titulo");
// Seleccionamos el botón que va a hacer el cambio.
const btnColor = document.querySelector("#btnColor");

btnColor.addEventListener("click", function () {
  // .style nos deja meternos al CSS del elemento desde JS.
  // .color es el color de la LETRA.
  titulo.style.color = "red";

  // Si les piden el color de FONDO, es así:
  titulo.style.backgroundColor = "yellow";
});
⚠️ OJO: en CSS se escribe background-color con guión, pero en JavaScript se escribe backgroundColor todo junto y con la C mayúscula. Lo mismo con font-size → fontSize.

2.B — Tamaño

const btnTamano = document.querySelector("#btnTamano");

btnTamano.addEventListener("click", function () {
  // fontSize cambia el tamaño de la letra.
  // IMPORTANTE: hay que ponerle la unidad ("px"), si no, no funciona.
  titulo.style.fontSize = "40px";

  // Si fuera una imagen o una caja, sería width o height:
  // imagen.style.width = "300px";
});

2.C — Value (el texto de un input)

const nombre = document.querySelector("#nombre");
const btnValue = document.querySelector("#btnValue");

btnValue.addEventListener("click", function () {
  // .value es lo que está ESCRITO dentro del input.
  // Ojo que aquí NO va .style, porque value no es CSS.
  nombre.value = "Hola profe, me saqué un 7";
});

2.D — Display (mostrar y ocultar)

const secreto = document.querySelector("#secreto");
const btnOcultar = document.querySelector("#btnOcultar");

btnOcultar.addEventListener("click", function () {
  // Preguntamos: ¿el párrafo está escondido?
  if (secreto.style.display === "none") {
    // si está escondido, lo mostramos
    secreto.style.display = "block";
  } else {
    // si se ve, lo escondemos
    secreto.style.display = "none";
  }
});
💡 ¿Por qué pregunto primero si es "none"? Porque al principio secreto.style.display está vacío (""), no dice "block". Si preguntan al revés (=== "block"), el primer click no les va a hacer nada y van a pensar que está malo. Si solo les piden ocultar (sin volver a mostrar), basta con secreto.style.display = "none"; y listo.

3) Eliminar un elemento con un botón

Esta es la más corta de todas, se los juro. Existe un método que se llama .remove() y hace exactamente lo que dice: borra el elemento de la página.

El HTML:

<div id="caja">📦 Bórrame si te atreves</div>
<button id="btnEliminar">Eliminar caja</button>

El JavaScript, paso a paso:

// 1. Seleccionamos el elemento que queremos borrar.
const caja = document.querySelector("#caja");

// 2. Seleccionamos el botón.
const btnEliminar = document.querySelector("#btnEliminar");

// 3. Cuando hagan click...
btnEliminar.addEventListener("click", function () {
  // ...borramos la caja. Chao, se fue, no existe más.
  caja.remove();
});
📦 Bórrame si te atreves

(si la borraste y la quieres de vuelta, recarga la página 😅)

⚠️ OJO: no confundan remove() con display = "none". El display la esconde (sigue ahí, pero no se ve). El remove la elimina de verdad. Si el examen dice "eliminar", usen remove().

4) Leer un input / búsqueda / select y mostrarlo en una alerta

Aquí la clave es una sola palabra: .value. Con eso leemos lo que el cliente escribió o eligió. Da lo mismo si es un input de texto, una barra de búsqueda o un select: todos se leen con .value.

4.A — Barra de búsqueda

El HTML:

<input type="search" id="buscador" placeholder="¿Qué buscas?">
<button id="btnBuscar">Buscar</button>

El JavaScript, paso a paso:

// 1. Seleccionamos la barra de búsqueda.
const buscador = document.querySelector("#buscador");

// 2. Seleccionamos el botón.
const btnBuscar = document.querySelector("#btnBuscar");

// 3. Cuando hagan click en buscar...
btnBuscar.addEventListener("click", function () {

  // 4. Leemos lo que el cliente escribió con .value
  //    y lo guardamos en una variable.
  //    OJO: esto va ADENTRO de la función, porque queremos
  //    leer lo que hay escrito EN EL MOMENTO del click.
  const textoBuscado = buscador.value;

  // 5. Mostramos la alerta juntando texto + la variable.
  alert("Buscaste: " + textoBuscado);
});

4.B — Select (lista desplegable)

El HTML:

<select id="selectComida">
  <option value="completo">Completo</option>
  <option value="empanada">Empanada</option>
  <option value="sopaipilla">Sopaipilla</option>
</select>
<button id="btnElegir">Elegir</button>

El JavaScript, paso a paso:

// 1. Seleccionamos el select.
const selectComida = document.querySelector("#selectComida");

// 2. Seleccionamos el botón.
const btnElegir = document.querySelector("#btnElegir");

// 3. Cuando hagan click...
btnElegir.addEventListener("click", function () {

  // 4. Leemos la opción elegida. Es IGUAL que el input: .value
  //    Nos devuelve lo que dice el value="" de la opción elegida.
  const comidaElegida = selectComida.value;

  // 5. Otra forma de juntar texto con variables: con comillas
  //    invertidas `` y ${}. Hace lo mismo que el +, úsenla si les acomoda.
  alert(`Elegiste: ${comidaElegida}. ¡Buena elección!`);
});
⚠️ ERROR TÍPICO: leer el .value afuera de la función. Si hacen const texto = buscador.value; arriba del addEventListener, se lee cuando carga la página (cuando está vacío) y la alerta siempre va a salir vacía. El .value se lee adentro del click.

5) Cambiar el src de una imagen

El src es la "dirección" de la imagen, o sea, de dónde la saca. Si le cambiamos el src, cambia la foto. Así de simple.

5.A — Cambiar la imagen con un botón

El HTML:

<img id="foto" src="img/dia.svg" alt="dibujo" width="200">
<button id="btnCambiar">Cambiar imagen</button>

El JavaScript, paso a paso:

// 1. Seleccionamos la imagen.
const foto = document.querySelector("#foto");

// 2. Seleccionamos el botón.
const btnCambiar = document.querySelector("#btnCambiar");

// 3. Cuando hagan click...
btnCambiar.addEventListener("click", function () {
  // 4. Le cambiamos el src por la ruta de la otra imagen.
  //    La ruta se escribe igual que en el HTML, entre comillas.
  foto.src = "img/noche.svg";
});

5.B — Cambiar la imagen al pasar el mouse (hover con JS)

Esto es lo mismo, pero en vez de escuchar un "click", escuchamos dos eventos distintos:

  • "mouseover" → cuando el mouse entra a la imagen
  • "mouseout" → cuando el mouse sale de la imagen

El HTML:

<img id="fotoHover" src="img/triste.svg" alt="carita" width="200">

El JavaScript, paso a paso:

// 1. Seleccionamos la imagen. Aquí NO hay botón,
//    la imagen misma es la que escucha.
const fotoHover = document.querySelector("#fotoHover");

// 2. Cuando el mouse ENTRA a la imagen, ponemos la carita feliz.
fotoHover.addEventListener("mouseover", function () {
  fotoHover.src = "img/feliz.svg";
});

// 3. Cuando el mouse SALE, volvemos a la original.
//    Si no hacemos este paso, se queda pegada en la feliz.
fotoHover.addEventListener("mouseout", function () {
  fotoHover.src = "img/triste.svg";
});

Pasa el mouse por encima 👇 (en el celu, tócala)

💡 Nota: las imágenes de esta guía están en la carpeta img/. En el examen el src va a ser la ruta de su imagen, tipo "img/perro.jpg" o "./assets/gato.png". Revisen bien la ruta: si la carpeta se llama "imagenes" y ustedes escriben "img", no va a aparecer nada.

✅ Checklist antes de entregar el examen

Si algo no les funciona, antes de entrar en pánico revisen esto (el 90% de los errores es alguno de estos):

  1. ¿Pusieron el # en el querySelector? Es querySelector("#miId"), no querySelector("miId"). Si es una clase, es con punto: ".miClase".
  2. ¿El id del HTML está escrito exactamente igual que en el JS? Mayúsculas y minúsculas importan: btnSumar no es lo mismo que btnsumar.
  3. ¿El <script> está al final del body?
  4. ¿El evento está bien escrito? Es "click", no "onclick" ni "Click".
  5. ¿Los valores de CSS llevan su unidad? "40px", no 40.
  6. ¿El .value lo leyeron adentro de la función?
  7. Abran la consola (F12 → Console). Si hay algo en rojo, ahí les dice en qué línea está el error. Léanlo, no muerde.
